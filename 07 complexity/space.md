# Space Complexity (Quick Notes)

- Measures how memory usage grows with input size.
- Expressed using **Big-O** notation.
- Only extra memory matters (not input size).
- Common memory uses:
  - Variables: O(1)
  - Arrays/Lists of size n: O(n)
  - 2D Arrays: O(n^2)
  - Recursion: O(depth of recursion)
- Iterative code usually O(1) space.
- Recursive code uses stack space.
- Optimize to reduce memory footprint.
