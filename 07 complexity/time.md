# Time Complexity (Quick Notes)

- Measures how runtime grows with input size.
- Expressed using **Big-O** notation.
- Focus on dominant term; ignore constants.
- Common complexities:
  - O(1): Constant time
  - O(log n): Logarithmic (Binary Search)
  - O(n): Linear (Single loop)
  - O(n log n): Log-linear (Efficient sorting)
  - O(n^2): Quadratic (Nested loops)
  - O(2^n): Exponential (Recursive combinations)
- Loops: Time = number of iterations.
- Nested loops: Multiply complexities.
- Recursion: Solve with recurrence relation.
- Worst-case complexity matters most.
